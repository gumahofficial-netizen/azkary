# تطبيق "مسلم"

تطبيق إسلامي متكامل احترافي تم تطويره باستخدام Flutter.

## المميزات الرئيسية
* **القرآن الكريم**: قراءة نصية كاملة مع استهلاك من API موثوق.
* **الأذكار**: مجموعة كاملة من أذكار حصن المسلم مع إمكانية التكرار والعداد.
* **مواقيت الصلاة**: حساب دقيق لمواقيت الصلاة بناءً على موقع المستخدم.
* **القبلة**: بوصلة دقيقة لتحديد اتجاه القبلة.
* **المزيد**: مسبحة إلكترونية، راديو إسلامي، قصص الأنبياء، وأدعية متنوعة.
* **إعدادات متقدمة**: دعم الوضع الليلي والنهاري، وتخصيص حجم الخط.

## هيكل المشروع
التطبيق يتبع بنية `Clean Architecture` لضمان الاحترافية وسهولة التطوير:
* `lib/core`: الثيمات والثوابت العامة.
* `lib/models`: نماذج البيانات (Surah, Adhkar, Dua, ...).
* `lib/services`: خدمات النظام (Audio, Notification, Prayer, Storage).
* `lib/providers`: إدارة الحالة (State Management).
* `lib/screens`: واجهات المستخدم (Screens & Tabs).

## التشغيل
لضمان عمل التطبيق، تأكد من تنفيذ الأوامر التالية من المجلد الرئيسي:
1. `flutter pub get`
2. `dart scripts/download_assets.dart`
3. `flutter run`
